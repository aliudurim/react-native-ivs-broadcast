# react-native-ivs-broadcast

Amazon IVS broadcast (RTMPS) and Real-Time Stages for React Native (New Architecture)

## Installation


```sh
npm install react-native-ivs-broadcast
```


## Usage


```js
import { IvsBroadcastView } from "react-native-ivs-broadcast";

// ...

<IvsBroadcastView color="tomato" />
```
